# 功能验证范围

本次移除额外桌面的改动使用只读实机验收、离线假窗口/假弹窗测试和 wheel 打包检查；未提交任何真实交易委托。

## 查询

| 功能 | 本次实机结果 | 限制 |
| --- | --- | --- |
| 资金 balance | 5 项字段成功 | 只测试本机登录态 |
| 持仓 position | 空表成功 | 非空持仓未验收 |
| 当日委托 today_entrusts | 16 条记录成功 | 非空数据表头/编号结构已检查 |
| 当日成交 today_trades | 空表成功 | 非空成交未验收 |
| 验证码临时前台 | 三个验证码均首轮通过 | 不承诺长期准确率；用户输入可能中断流程 |
| 禁止验证码前台输入 | 明确失败，自有验证码取消，主窗口隐藏 | 客户端自动弹出的验证码仍可能短暂显示 |
| 结束收起/归还焦点 | 验证码关闭、主窗口隐藏、返回原前台 | 用户已主动切换其他应用时不抢回 |
| 额外任务视图桌面 | 已删除两个旧空桌面 | 保留用户原有三个桌面；运行代码不再管理桌面 |

## 交易接口

查询对象 `easytrader.use("ths", background=True)` 的买卖、撤单、打新、回购、登录接口全部抛 PermissionError；此限制有离线测试，未开放后台交易。

前台 `ClientTrader` 的状态必须单独说明：

| 接口 | 当前状态 | 此次验证 |
| --- | --- | --- |
| buy / sell 限价 | 实现确认弹窗代码/价格/数量/方向核对；缺失基线或方向时在确认前失败 | 离线回归，未用修改后的代码提交真实委托 |
| market_buy / market_sell | 同花顺路径暂不支持，提交前抛错 | 验证不会填写或提交；其他券商保留原路径 |
| cancel_entrust 单笔 | 定位后拒绝执行未验证的单笔路径，绝不退回全撤 | 目标存在、不存在、空编号等路径均验证不会调用全撤 |
| cancel_all_entrusts 全撤 | 保留已有前台实现 | 此次未发指令；仍不能仅凭按钮或弹窗结束判定券商已撤 |
| auto_ipo | 空数量/字符串数量已容错，未知结果明确返回 unknown | 离线测试，实际可申购行选择与提交未验收 |
| repo / reverse_repo | 更正路径文字并精确匹配菜单，解析融资/融券确认字段 | 离线测试，实际回购未验收 |

单笔撤单此前错误调用全撤，已删除这一危险降级。不能把“现在安全拒绝执行”称作“单笔撤单可用”。市价路径也不能称作已跑通。

新增的交易保护还包括：委托号只从编号字段提取，返回纯编号；拒绝缺失提交前基线的下单；多笔候选不猜；废单/失败/已撤记录不当成功；委托数量不再以截断小数方式匹配。

## 离线与分发检查

最终离线运行以本次提交前 pytest 输出为准。所有 GUI 保护测试使用假原生 API，没有把真实账户接入测试套件。环境变量启用的历史券商集成测试保持跳过，不应在真实资金账户上开启。

wheel 检查确认包含 query_captcha 模块、ONNX 模型及外部数据；依赖中不含 pyvda，且不包含已删除的桌面控制工具。
