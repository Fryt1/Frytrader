# 同花顺独立桌面控制面板

双击仓库根目录的 **打开同花顺独立桌面.cmd**。无需管理员权限，无需输入命令，也不安装另一套交易软件。

## 日常操作

1. 打开控制面板，等待显示“返回按钮已就绪”。
2. 如果远航版尚未运行，点 **在独立桌面启动远航版**。使用你已经安装的远航版主程序 `bin/happ.exe`，再从远航版中打开下单窗口。
3. 点 **进入同花顺桌面**，在里面手动登录、切换下单窗口的新旧版。
4. 完成后点独立桌面左上角始终置顶的 **返回工作桌面**。

独立桌面没有普通桌面的任务栏。返回面板常驻，不需要寻找命令行或在那个桌面打开文件。点击返回面板的关闭按钮也会返回工作桌面。默认最长停留 180 秒，可在进入前调整；控制进程和返回面板分别监控超时，即使一个进程失去响应，另一个仍可尝试返回。

切换桌面不会主动关闭远航版。关闭控制面板也不会关闭远航版。券商会话仍可能因超时、断线或程序退出而需要重新登录，工具不承诺永久登录，也不保存密码。

## 保留现有登录

已经在工作桌面运行的远航版不能直接搬到独立桌面。工具会保留原实例并拒绝再开一个，不会强制退出它。

如果需要改到独立桌面运行，先自行退出正常桌面的远航版，再用面板启动。切换回工作桌面时不要退出同花顺，否则登录态也会随客户端退出。

## 验证范围

当前实现的是 **便捷切换和返回保护**。已验证返回面板确实运行在指定独立桌面，默认桌面看不到它；自动测试未切走用户屏幕。

**完整的远航版后台查询尚未验收。** 现有 `ClientTrader` 仍包含 `type_keys`、`set_focus` 等前台输入逻辑。创建独立桌面不意味着这些全局输入就会安全地发往非活动桌面。因此此控制面板不自动调用账户查询或交易，不应直接把原来的查询脚本放到独立桌面后无人值守运行。后续需在独立工作进程中验证消息输入、截图和查询链路。

Windows 锁屏或 UAC 安全提示期间可能禁止切换。程序不会跳过安全桌面，会保留返回请求，解锁后重试。

## 离线检查

```powershell
python -m unittest tests.test_desktop_control
python tools/desktop_panel.py --self-test
```

第一条检查固定返回目标、超时、锁屏、辅助进程退出等边界；第二条只在临时测试桌面启动和检查返回面板，不切换输入桌面，不操作同花顺，结束后清理自己的进程和桌面句柄。
