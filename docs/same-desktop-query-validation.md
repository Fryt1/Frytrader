## 前期全程隐身实验（已放弃，不是当前验收条件）

隐藏下单窗口而保持原 owner 的任务视图登记时，资金字段可读取；表格复制会自行创建 visible=true 的验证码。旧激活保护只阻止激活，不能阻止显示，所以全程隐身条件未通过。

首次同时隐藏 owner/trader 后恢复显示时，owner 的 AppView 被重新登记到工作桌面；已及时恢复原归属，未继续用该恢复路径宣称隐身成功。

在临时非输入 Win32 桌面上验证显示拦截原型（HCBT_CREATEWND + WH_CALLWNDPROC）时，三个合成显示路径未通过。原型未接入真实客户端或发布包。用户随后明确接受输入需要前台，故停止此方向，改为当前混合模式。
